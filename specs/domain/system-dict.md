# 系統字典（System）

> **管什麼**：字典分組 / 字典項的層級、識別碼、排序、停用傳染、篩選語義，以及前端的樹形下拉。
> **何時讀**：動 `sys_dict`、`DictTreeSelect.vue`、`utils/dicts.ts`，或任何「分類下拉 / 按分類篩選」時。
> **改到這裡要同步**：`frontend/scripts/check-dicts.ts`（純函數檢查）、`specs/status.md` 的 System 條目。

---

## 層級與識別碼

- `sys_dict` 有 `ParentId`（自引用，同一分組內多層），用來表達「牛房 → 一樓 / 二樓」這類歸屬；只建 EF 導航（`Parent` / `Children`），**不建資料庫 FK**。
- 識別碼（`Value`）由系統按層級自動生成：頂層 `1`、`2`；下級跟在所屬上級後面編 `1.1`、`1.2`，孫級 `1.1.1`。識別碼**一律不可手動修改**，換上級時自動重新編號，所以歷史打印／導出仍能從編號看出層級。
- 上級必須存在且屬於同一分組；不能歸到自己的下級之下（成環防護）；有下級的項不能再歸到其他上級之下（要先移走下級），也不能被刪除。
- 識別碼是**派生值**，所以字典引用遵循「id 為準、code 作可讀別名」——詳見 [architecture.md 的「標識符」](../architecture.md#標識符id-為準code-作可讀別名)。分層分組只能按 id；只有扁平分組（`materials` / `receipt`）的 code 可以當查詢參數。

## 前端顯示

- 字典頁用樹形表格顯示（預設全展開，可逐行收起）。**樹形的第一欄必須是「標籤」**——Element Plus 的縮進注入在第一個普通欄，放到索引／排序欄會變成「看起來扁平」而且把那一欄擠亂。標籤放第一欄、識別碼獨立成欄，行高才不會被第二行說明文字撐開。
- 所有系統字典下拉（會計票據、考勤地盤／職位、文件庫類別、字典上級選擇）一律用 `frontend/src/components/DictTreeSelect.vue` 的樹形下拉，用 `frontend/src/utils/dicts.ts` 的 `dictTree()` 出樹、`dictPath()` 出「牛房 / 一樓」路徑；選完輸入框顯示完整路徑。不要用扁平的「父 · 子」字串，也不要自己再拼字串或另寫排序。
- **同層排序先按 `Sort`、再按識別碼**（`1.10` 排在 `1.9` 之後），表格與下拉共用同一條規則；「上移／下移」只在同一層（同一個 `ParentId`）內換位，後端仍按整組 id 的順序重排。
- 樹形下拉要能選有下級的上級節點（`check-strictly`），否則「牛房」這種還有下級的地盤就點不了；停用項預設隱藏（`allow-disabled` 用於查歷史），已選中的停用項維持可顯示。
- **接口不重複返回字典名稱**：列表 / 詳情 DTO 只回字典項 id（`type`、`siteCategoryDictId`…），前端用已載入的字典按 id 映射（`dictText()`）。例外是真正落庫的歷史快照（薪酬表 `Position` / `Site` 欄）和 ZIP 導出時內部用的文件夾名稱。

## 停用

- **停用沿層級向下生效**：上級停用等於整條分支都不再用，下級在下拉裡一併變灰（`DictTreeSelect` 遞迴傳 `disabled`），寫入端也一併拒絕——`SysDictService.EnsureEnabledAsync(id, groupName, message)` 檢查自己與每個上級都啟用，錯誤訊息點名是哪個上級停用了。
- 已經存下來的資料不受影響：列表、詳情、ZIP 導出照舊，`allow-disabled` 的歷史篩選仍能選到停用子項。刻意只驗分組不驗啟用的地方（打卡明細編輯、員工職位）也不驗上級，保持「歷史資料可以改」的既有語義。
- 停用有下級的上級時前端會先確認一次；字典頁對這種下級標「上級停用」。

## 按分類篩選

- **篩選一律含下級**：所有列表篩選（文件庫文件類別、會計票據列表、考勤薪酬表的地盤／職位）選上級時要連同其整棵子樹的記錄一起返回，前端不給開關。
- 後端擴張用 `SysDictService.SubtreeIdsAsync(rootId)`（按 `ParentId` 收集，不按識別碼前綴——識別碼會在換上級時重新編號，只是顯示用的派生資料；含停用項，歷史記錄掛在停用子分類上不能漏）。
- 只有 ZIP 導出（會計「提取圖片」）加「包含下級」開關（默認開，`includeDescendants=false` 才只取該分類本身）。
- 表單單選（打卡、員工職位、票據表單、上傳類別、字典上級）不涉及子樹語義，不做擴張。
