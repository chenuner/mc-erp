# design-system.md — 前端設計系統

> 決定"長什麼樣"。所有前端頁面的視覺與交互依據，與 tech-stack.md / architecture.md 並列。
>
> 原則：**專業工程感，數據高可讀，克制不炫技。** 一份文件夠用，不拆多文件。

---

## 風格定位

**Data-Dense Dashboard（數據密集型儀表盤）+ 專業工程感** — 建築管理行業氣質：沉穩、清爽、高效。

- KPI 卡片、圖表、數據表格網格化佈局，空間高效、數據可見性最大化
- 淺色工作區 + 深色側邊欄的對比佈局
- 拒絕通用後台模板臉、拒絕華麗堆砌

---

## 布局

- **左側深色固定導航**：四大模組（考勤 / 會計 / 文件 / 系統）+ 二級菜單，可折疊
- **頂部工具欄**：麵包屑、全局搜索、通知、當前用戶
- **內容區**：卡片化分區，統一柵格，間距只用 16px / 24px 兩檔
- 各頁面容器最大寬度一致，任何分辨率不留水平滾動

---

## 色彩

工程藍主色（安全帽 / 工程圖意象），語義化狀態色貫穿各模組。

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | `#1D5BBF` | 主按鈕、鏈接、激活態 |
| 主色亮 | `#2E73E8` | hover / 漸變輔助 |
| 主色淺底 | `#E8F0FC` | 選中行、標籤底色、信息面板 |
| 頁面背景 | `#F5F7FA` | 內容區底色 |
| 卡片背景 | `#FFFFFF` | 卡片、表格、表單容器 |
| 側邊欄 | `#1B2432` | 深色導航底色 |
| 主文本 | `#1F2937` | 標題、正文 |
| 次要文本 | `#6B7280` | 描述、佔位、輔助說明 |
| 側邊欄文本 | `#C9D4E4` | 導航菜單文字 |
| 成功 | `#18A058` | 已審計、已月結、正常打卡 |
| 警告 | `#E6A23C` | 待確認、遲到、臨期 |
| 危險 | `#D9363E` | 刪除、異常、超支 |

### Element Plus 主題變量映射

統一在 `frontend/src/styles/` 下覆蓋 CSS 變量，禁止頁面內寫死色值：

```css
:root {
  --el-color-primary: #1D5BBF;
  --el-color-success: #18A058;
  --el-color-warning: #E6A23C;
  --el-color-danger:  #D9363E;
  --el-border-radius-base: 8px;
}
```

## 字體

- 中文：`PingFang SC` → `Microsoft YaHei` → 系統無襯線，font-display 無阻塞
- 數字：金額、日期、工時等關鍵數字字段一律 `font-variant-numeric: tabular-nums` 對齊
- 層級：

| 層級 | 字號/字重 | 用途 |
|------|-----------|------|
| 頁面標題 | 24px / 600 | 頁面名稱 |
| 區塊標題 | 18px / 500 | 卡片、分區標題 |
| 正文 | 14px / 400 | 表格、表單、正文 |
| 輔助 | 12px / 400 | 註釋、標籤、時間戳 |

---

## 組件風格（Element Plus 定制）

- **圓角**：卡片 / 輸入框 / 按鈕 8px，標籤等小元素 6px
- **卡片**：1px 邊框（`#E5E7EB`）+ 輕投影；hover 陰影加深 + 微上浮，過渡 200ms
- **表格**：斑馬紋、行 hover 高亮、固定表頭、列寬可配置；數據密集表必須帶篩選
- **按鈕**：主操作工程藍；危險操作（刪除、月結）紅色 + 二次確認對話框
- **表單**：Element Plus 內置校驗規則，即時反饋；輸入框必須有 label，禁止純佔位符
- **空狀態**：SVG 插畫 + 一句引導文案，不堆文字
- **頁籤**：膠囊化（圓角激活態）

---

## 圖標

- 全部使用 **Lucide 線性 SVG 圖標**，24x24 基準，線寬 1.5-2px
- **禁止 emoji 圖標**，禁止混用多套圖標風格
- 用 `lucide-icons` 技能獲取與定制

---

## 交互與動效

- 過渡統一 150-300ms；hover 用顏色 / 陰影反饋，**不用 scale 位移**（避免佈局抖動）
- 所有可點擊元素 `cursor: pointer`，鍵盤焦點態可見
- 異步加載一律 skeleton 屏或 spinner，禁止空白等待；提交按鈕 loading → 成功/失敗消息
- 動效僅限：路由切換淡入、統計卡計數動畫、加載指示器；裝飾性無限動畫禁止
- 尊重 `prefers-reduced-motion`

## 圖表

| 場景 | 圖表類型 | 要點 |
|------|---------|------|
| 薪酬 / 工數月度趨勢 | 折線圖 | 多序列用區分色，20% 透明度填充 |
| 各地盤支出對比 | 柱狀圖 | 降序排列 + 柱頂數值標籤 |
| 支出分類佔比 | 環形圖 | 中心放總計，限 5-8 類 |

- 圖表庫**必須先加入 tech-stack.md 才可引入**（候選：ECharts，Element Plus 生態配套），禁止先斬後奏
- 色盲無障礙：趨勢線附加圖案區分，關鍵圖表提供數據表下載

---

## 無障礙

- 文本對比度 ≥ 4.5:1（深色側邊欄文本用 `#C9D4E4`，不用更暗）
- 表單輸入必須關聯 label；顏色不是唯一狀態指示（配圖標 / 文字）
- 鍵盤可完成全部操作，焦點環可見

---

## 反模式（禁止）

- 華麗堆砌、模板臉、過度裝飾（ornate design）
- 無篩選 / 無分頁的數據表格
- 裝飾性無限循環動畫
- emoji 圖標、scale 位移 hover
- 頁面內寫死色值，繞過主題變量
- 引入第二個 UI 庫或未列入 tech-stack 的表單校驗庫（如 VeeValidate）

---

## 交付檢查清單

- [ ] 無 emoji 圖標，圖標全部 Lucide、尺寸統一
- [ ] 可點擊元素 `cursor: pointer`，hover 有明確反饋
- [ ] 過渡 150-300ms，無佈局抖動
- [ ] 淺色模式文本對比 ≥ 4.5:1
- [ ] 異步操作有 skeleton / spinner / 提交反饋
- [ ] 響應式：1024px / 1440px 無水平滾動
- [ ] 表單有 label、鍵盤焦點可見
- [ ] 色值全部走主題變量
